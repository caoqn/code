- When auditing generated solution artifacts, first inventory every file and inspect each module's imports/public symbols, then run syntax checks and focused behavioral smoke tests; explicitly separate static evidence from dependency-blocked runtime evidence.
- Before performing batched external mutations, establish an authoritative preflight inventory and stable ownership map, then check each target for an existing matching mutation; create only missing items and verify the final count and uniqueness by readback.
- When independent readbacks disagree, stop completion claims and reconcile using stable target IDs plus API-reported totals and pagination limits; record the conflict explicitly rather than averaging or choosing a favorable result.
- When validating generated tabular artifacts, compare both schema order and semantic row content against the required template and authoritative source; verify the documented composite ordering key explicitly, then reconcile manifest keys and counts independently.
- Before writing ad hoc smoke tests for a changed API, inspect its constructor/signature and nearby tests so probes use valid invocation patterns and avoid misleading failures.
- Before manual behavioral probes, inspect the module's documented constants or existing tests to confirm exact accepted option names; avoid treating invalid probe parameters as implementation failures.
- When teammates may be writing artifacts concurrently, perform a final stable inventory only after writes are declared complete; rerun inventory after cleanup and distinguish transient observations from the authoritative final state.
- Before endorsing a generated patch, inventory the entire requirement context and trace every public import/dependency from the application entry point through routes, services, and tests; distinguish feature-local correctness from repository-wide completeness, and require at least one real endpoint smoke test when HTTP behavior is claimed.
- When native and local authoritative readbacks diverge, identify which store the evaluator validates before mutating; reconcile both stores or explicitly block completion rather than assuming API state is sufficient.
