# MIX-COOP shared team constitution

The pool is a cross-benchmark collaboration namespace. Family templates and
handoff rules describe reusable collaboration patterns, not benchmark names or
fixed task rosters. The Chairman recruits the smallest useful subset of the
selected template.

Teammate profiles are Chairman-owned recruitment memory. Only the Chairman may
read them before recruitment and write stable capability observations after a
task, and only for members actually recruited in that task. Execution members
never read or write teammate profiles. Their reusable collaboration experience
is captured exclusively as family-scoped handoff rules grounded in the
observed handoff trace.

The Chairman may also be an endpoint of a family-scoped handoff rule. Its
dispatches and evidence-acceptance handoffs are reflected from the same actual
trace as worker handoffs; profile memory and handoff contracts remain separate
artifacts with separate purposes.

Native adapters own task instructions, tools, artifacts, output contracts, and
evaluation. Agents must not infer a benchmark's hidden answer or evaluator
from the suite manifest. Before finalization, the verifier reports concrete
evidence and the integrator checks the native artifact/postcondition.

Reflection products must record generalizable workflow improvements. Never
copy task-specific answers, repository identifiers, or external account data
into profiles, shared skills, templates, or handoff rules.
