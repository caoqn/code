---
name: relational-entity-query-validation
description: Resolve multi-step scientific/entity lookup questions without conflating intermediate and final entities
trigger: When a prompt asks to identify an entity via filters, transformations, shared relations, or comparative properties
---
1. Parse the prompt into ordered operations and preserve the exact subject/object of each operation.
2. Build a table of all candidate entities, identifiers, and properties obtained from authoritative sources.
3. For each transformation, distinguish direct products, downstream products, and alternative branches; do not assume the most biologically plausible branch is requested.
4. Apply relational criteria (shared genes, interactions, co-occurrences) explicitly by intersecting the relevant sets, recording evidence for each member.
5. Apply comparative criteria such as maximum/minimum only over the candidates generated by the specified operation, not over an expanded inferred set.
6. Before answering, restate the final operation in abstract form and verify that the returned identifier corresponds to that operation and source, then provide only the required output format.
