---
name: time-boxed-code-reading
description: Efficient workflow for analyzing assigned code while preserving implementation time
trigger: When assigned repository analysis during a constrained engineering task
---
1. Confirm the exact files and questions to answer; do not broaden scope without evidence.
2. Read targeted sections first (interfaces, configuration, integration points), limiting each file to relevant excerpts.
3. Produce one concise report with actual signatures/snippets, dependencies, and risks.
4. Include a minimal verification suggestion so the implementer can validate independently.
5. Stop after the report; avoid repeated status messages or speculative extra exploration unless requested.
