---
name: time-boxed-integration
description: Efficient workflow for mapping requirements to an implementation in a large repository
trigger: When assigned repository analysis or feature integration work under a limited time budget
---
1. Extract the requirements and edge cases into a short checklist.
2. Immediately delegate parallel scans of configuration, analogous components, tests, and integration points.
3. Read only files directly implicated by the delegated findings; stop exploration once each checklist item has concrete evidence.
4. Send the implementer one consolidated map containing paths, symbols, conventions, and verification commands.
5. Avoid iterative status chatter; request updates only at meaningful milestones.
6. Time-box review and verification, prioritizing blockers and missing wiring over stylistic concerns.
