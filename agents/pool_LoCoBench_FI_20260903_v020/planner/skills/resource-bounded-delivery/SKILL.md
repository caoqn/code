---
name: resource-bounded-delivery
description: Coordinate multi-agent engineering tasks while preserving a final verification and submission window.
trigger: When a task involves multiple agents, broad repository context, or a strict time/message budget.
---
1. Perform a single brief requirement and file-scope scan.
2. Recruit only the implementer plus non-overlapping evidence specialists needed for the scope; avoid redundant reviewers unless time permits.
3. Dispatch all assignments immediately with concrete file targets, acceptance criteria, and a report deadline.
4. Set internal checkpoints: evidence arrival, implementation cutoff, and final verification/submission window.
5. Allow the implementer to proceed when core evidence is available; do not wait indefinitely for optional reports.
6. Limit coordinator status checks and relay messages to one checkpoint; require concise updates.
7. Near the cutoff, prioritize artifact existence and interface checks over iterative polishing, and submit the best complete solution before time expires.
