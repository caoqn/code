---
name: archival-list-to-primary-source
description: Identify a person or event from a dated list and verify it in the underlying primary archive.
trigger: When a question asks who performed an action recorded in a dated archive or list.
---
1. Locate the authoritative dated index or list using targeted searches.
2. Inspect the relevant date section and enumerate all candidate entries; filter candidates by the question's subject criteria.
3. Open the underlying archive linked from the index for the selected entry.
4. If normal page retrieval fails (rate limits, rendering issues), request the page's raw/source representation or use a mobile mirror, while preserving the canonical URL.
5. Extract the exact labeled field requested (for example, “Nominator(s)”) and record timestamps and actors separately to avoid confusing approver with initiator.
6. Cross-check the result against the index's summary field and provide both index and primary-archive URLs, quoting the decisive lines.
