- When a research question identifies a target by an exclusion criterion (for example, an article lacking a term), enumerate the full candidate set, verify the criterion directly in each source, and resolve wording ambiguities by matching the requested noun and any transformation instructions exactly.
- When delegating a problem, include the complete task statement, all operational rules, and required output format in the first assignment message so specialists can work without clarification rounds.
- When independent verification has been requested for a strict factual answer, wait for it unless the task has a time-critical constraint; if submitting earlier on directly quoted primary evidence, explicitly document why the remaining verification is redundant.
- For time-bounded research tasks, dispatch the smallest evidence team immediately, give each researcher a distinct source or extraction route, and set a short checkpoint that requires either the decisive data or a concrete blocker; if a route is blocked, pivot or synthesize from corroborated partial evidence rather than waiting indefinitely.
- For strict short-answer prompts that ask for the name of a character or item, return only its canonical shortest name, even when the reasoning establishes that multiple instances of that same character/item are required; do not add quantity unless the prompt explicitly asks how many.
- For calculations tied to a historical paper, never label an equation as 'likely' or rely on a modern equivalent: obtain the exact final displayed equation and definitions from the specified translation, then map spreadsheet columns by those definitions; independently test any alternate parameter interpretation before finalizing.
