---
name: assignment-puzzle-document-analysis
description: Solve document-based assignment puzzles where observed items must be matched to profiles and a missing actor inferred.
trigger: When an attachment lists people, preferences, assignments, and incomplete outcomes requiring identification of a missing participant.
---
1. Extract the full document, including tables, headings, and captions; preserve table headers and row direction.
2. Separate the evidence into participant profiles, assignment pairs, and observed outcomes.
3. Match each outcome to a profile using the most specific compatible clue, and list unmatched profiles or outcomes.
4. Determine whether each assignment arrow is giver-to-recipient or recipient-to-giver from headers and the problem wording; do not infer the missing actor solely from the unmatched profile.
5. Trace the unmatched recipient or outcome through the assignment table to identify the requested actor.
6. Independently validate the mapping and report the exact requested name in the required short-answer format.
